# Security

Please report a security problem in this plugin or in Hazelchat to hello@hazelchat.co, with "Security" in the subject. We answer within one business day and fix confirmed problems in a new release.

The plugin prints one script tag with your public widget key, which is not a password. It makes no requests from Kirby, stores only that key and one switch in your site content, and only administrators can change them in the Panel.
